# Magari Zetu 

A full-stack car dealership web application built for a real client.

## Live Demo
Coming soon

## Features
- Browse and search cars with advanced filters
- Car detail pages with image gallery and TikTok video integration
- Customer accounts with email verification
- Save favourite cars
- Personalised car recommendations
- WhatsApp and call inquiry buttons
- Admin dashboard to manage car listings
- Site analytics — customer activity and car views
- Dark and light mode
- Fully responsive on all devices

## Tech Stack
**Frontend:** React, Vite, plain CSS  
**Backend:** Node.js, Express.js  
**Database:** MongoDB Atlas  
**Image hosting:** Cloudinary  
**Authentication:** JWT + bcryptjs  
**Email:** Nodemailer + Gmail  
**Hosting:** Render  

## Security
- Email verification on registration
- Strong password requirements
- JWT authentication
- Rate limiting
- Helmet.js security headers
- Environment variables for all secrets
